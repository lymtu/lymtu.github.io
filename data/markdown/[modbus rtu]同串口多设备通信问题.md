> 本文只基于我所接触到的设备的情况，并不能代表所有设备、串口连接

基于上文的PLC程序改造，测试均为串口-设备一一对应通信，而切换到同串口负责两台及以上设备时，通信存在问题，具体表现为：

```txt

# 以下均为同串口通信

# 03后请求第一个设备，响应正常

设备A-03  -> 设备B-[任意功能码]

# 06后请求其它设备，无响应（无论后续请求几次

设备A-06  -> [任意非A设备]-[任意功能码]

# 06后对同设备03，在请求第二个设备，响应正常

设备A-06  -> 设备A-03  -> 设备B-[任意功能码]

```

所以得出解决方法为，06请求得到响应后，执行者捏造一个03请求，以恢复后续通信。

---

这种情况不确定是设备问题还是RS-485问题，也有可能是我所接触到的硬件有问题，所以无法确定本文方法能解决所有相同情况。
